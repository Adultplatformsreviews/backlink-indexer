Host this app on a domain you own so Google, Bing, and others can crawl the hub, sitemap, and feeds. Set the public base URL in Settings to the public origin (for example https://indexer.yourdomain.com). Google’s sitemap ping endpoint is deprecated and is not used.

Public discovery URLs

Submit these in Bing Webmaster Tools (and optionally Google Search Console as a sitemap of your hosted hub, not of the third-party pages themselves). The HTML hub lists each backlink as a normal hyperlink.

What the hub includes

Public hosting

Needed so feed pings and IndexNow key URLs resolve on a real domain.

IndexNow

Bing, Yandex, Seznam and others. The key file must be served on the same host as the URLs you submit. That means third-party backlinks cannot be submitted unless you control those hosts. Use it for this app’s hub pages and any site you mark as owned.

Owned hosts

Hosts you control and can place an IndexNow key file on (or have verified in Search Console). Do not add third-party sites.

    Google Indexing API Own site only

    Upload a Google Cloud service-account JSON. The account must have access to your Search Console property. Officially intended for job postings and livestream pages. It will not index someone else’s blog post that links to you.
